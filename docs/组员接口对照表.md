# 组员接口对照表

> 先看清一件事：**对外 HTTP 接口全部由组长 A 的 FastAPI 提供。**  
> 组员不是各自再写一套 `/api/...`，而是实现「接口背后真正干活的能力」；中台去调用你们。

```text
前端 / Swagger  →  组长 FastAPI（已有）  →  组员模块（你们要实现）
```

除 `/health`、`POST /api/auth/login` 外，均需 Header：

```http
Authorization: Bearer <access_token>
```

Token 来自登录接口（账号 `demo` / `demo123`）。

---

## 0. 总览

| 角色 | 对外 HTTP（组长已写路由） | 你真正要实现的 |
|---|---|---|
| **A 组长** | 全部接口 | 中台编排、鉴权、调组员 |
| **B 爬虫** | `/api/crawler/*`（间接支撑 `/api/news`） | `run_crawl(source_id)` |
| **C 知识库** | `/api/knowledge/*`（支撑 `/api/chat` 检索） | `upload` / `search` |
| **D AI** | `/api/chat`、`/api/analyze`、`/api/alert/evaluate` | Dify 三条 `run(workflow_key, inputs)` |
| **E 通知+前端** | `/api/notify/*`；前端消费几乎所有接口 | `send_dingtalk` / `send_email` + 5 页面 |

完整字段定义：`docs/openapi.yaml`、`packages/schemas/`。

## 1. 成员 B —— 爬虫 / 入库

### 1.1 对外接口

#### `POST /api/crawler/start` 启动采集

**请求：**

```json
{"source_id": "all"}
```

| source_id | 含义 |
|---|---|
| `miit_policy` | 政策 |
| `ev_news` | 行业新闻 |
| `oem_news` | 车企动态 |
| `all` | 三个都采 |
| `demo_recall` | 答辩用召回新闻 |

**响应：**

```json
{
  "task_id": "a1b2c3d4e5f6",
  "source_id": "all",
  "status": "success",
  "fetched": 20,
  "parsed": 18,
  "dropped_short": 2,
  "inserted": 4,
  "duplicated": 14,
  "error_message": null,
  "started_at": "2026-08-19T10:00:00",
  "finished_at": "2026-08-19T10:00:05"
}
```

`status`：`pending` | `running` | `success` | `failed`

#### `GET /api/crawler/status` 任务状态

| 参数 | 位置 | 说明 |
|---|---|---|
| `task_id` | query，可选 | 不传 = 最近一次 |

响应结构同上。

#### `GET /api/news` / `GET /api/news/{id}`（B 入库后供全组查询）

```http
GET /api/news?category=risk&days=7&page=1&page_size=20
```

| 参数 | 说明 |
|---|---|
| `category` | `policy` \| `company` \| `market` \| `tech` \| `risk` \| `other` |
| `days` | 近几天，默认 7 |
| `page` / `page_size` | 分页 |

### 1.2 B 要实现的函数

```python
def run_crawl(source_id: str) -> CrawlResult: ...
```

**入库新闻字段（必须对齐）：**

```json
{
  "title": "某车企宣布召回12万辆新能源车",
  "published_at": "2026-08-18T09:00:00+08:00",
  "source": "ev_news",
  "source_url": "https://example.com/n/1",
  "category": "risk",
  "company": "XX汽车",
  "content": "正文……（建议不少于约80字）",
  "content_hash": "sha256(title+source_url)",
  "keywords": ["召回", "新能源"],
  "is_duplicate": false
}
```

对接：告诉组长后改 `CRAWLER_MODE=local`（或 `http`）。

## 2. 成员 C —— RAGFlow 知识库

### 2.1 对外接口

#### `POST /api/knowledge/upload`

`multipart/form-data`，字段名：`file`。

**响应：**

```json
{
  "document": {
    "id": 1,
    "filename": "X1产品说明书.pdf",
    "dataset": "enterprise",
    "status": "ready",
    "chunk_count": 12,
    "created_at": "2026-08-19T10:00:00"
  }
}
```

#### `GET /api/knowledge/search`

| 参数 | 说明 |
|---|---|
| `query` | 问题；**空** = 只返回文档列表 |
| `top_k` | 引用条数，默认 5 |

**响应：**

```json
{
  "query": "X1最大日处理能力",
  "citations": [
    {
      "doc": "X1产品说明书",
      "page": 13,
      "snippet": "X1产品最大日处理能力为6800件。",
      "score": 0.92
    }
  ],
  "documents": []
}
```

### 2.2 C 要实现的函数

```python
def upload(filename: str, content: bytes) -> KnowledgeDocOut: ...
def search(query: str, top_k: int = 5) -> list[Citation]: ...
```

验收：问「X1 最大日处理能力」→ **6800** + 页码出处。

对接：`RAG_MODE=http`，填 `RAG_BASE_URL`。

## 3. 成员 D —— Dify 工作流

### 3.1 对外接口 ↔ 工作流

| HTTP | Dify key | 作用 |
|---|---|---|
| `POST /api/chat` | `wf_knowledge_qa` | 知识问答 |
| `POST /api/analyze` | `wf_industry_brief` | 行业周报 |
| `POST /api/alert/evaluate` | `wf_risk_alert` | 风险研判 |

#### `POST /api/chat`

```json
{"query": "X1产品最大日处理能力是多少？"}
```

```json
{
  "answer": "……6800件……",
  "citations": [{"doc": "X1产品说明书", "page": 13, "snippet": "…", "score": 0.92}],
  "workflow": "wf_knowledge_qa"
}
```

#### `POST /api/analyze`

```json
{"range_days": 7}
```

```json
{
  "id": 1,
  "title": "新能源汽车行业智能情报周报（近7天）",
  "kind": "weekly",
  "range_days": 7,
  "content_md": "## 一、本周行业概况\n…",
  "created_at": "…"
}
```

`content_md` 必须含六个标题：行业概况 / 重要政策 / 重点企业动态 / 技术进展 / 市场动态 / 趋势与建议。

#### `POST /api/alert/evaluate`

```json
{"news_id": 1}
```

```json
{
  "alert_id": "alrt_20260819100000_001",
  "level": "high",
  "company": "XX汽车",
  "title": "宣布召回12万辆汽车",
  "summary": "……",
  "impact": "可能影响品牌信誉及供应链订单",
  "suggestion": "核对本公司是否使用相关零部件",
  "news_id": 1,
  "citations": [],
  "created_at": "…"
}
```

`level`：`low` | `medium` | `high` | `critical`（含「召回」建议 ≥ `high`）

列表：`GET /api/alerts?page=1&page_size=20`、`GET /api/reports?page=1&page_size=20`

### 3.2 D 要实现的函数

```python
def run(workflow_key: str, inputs: dict) -> dict: ...
```

| workflow_key | inputs | 返回要点 |
|---|---|---|
| `wf_knowledge_qa` | `query`, `citations` | `answer`, `citations` |
| `wf_industry_brief` | `range_days`, `news[]` | `title`, `kind`, `content_md` |
| `wf_risk_alert` | `news`（一条新闻） | `level`, `company`, `title`, `summary`, `impact`, `suggestion`, `citations` |

对接：`DIFY_MODE=http`，填 `DIFY_BASE_URL`、`DIFY_API_KEY`。

## 4. 成员 E —— 钉钉 / 邮件 / 前端

### 4.1 通知接口

#### `POST /api/notify/dingtalk`

```json
{"alert_id": "alrt_20260819100000_001"}
```

```json
{"ok": true, "channel": "dingtalk", "message": "【智讯通·行业重要事件提醒】…"}
```

钉钉正文模板（锁死）：

```text
【智讯通·行业重要事件提醒】
企业：{company}
事件：{title}
风险等级：{level}
影响分析：{impact}
建议：{suggestion}
```

#### `POST /api/notify/email`

```json
{
  "kind": "alert",
  "alert_id": "alrt_20260819100000_001",
  "to": "demo@example.com"
}
```

或：

```json
{"kind": "daily", "report_id": 1, "to": "demo@example.com"}
```

| 字段 | 说明 |
|---|---|
| `kind` | `alert` \| `daily` |
| `alert_id` | `kind=alert` 时需要 |
| `report_id` | `kind=daily` 时可选（不传发最新报告） |
| `to` | 收件人，可空 |

### 4.2 E 要实现的函数

```python
def send_dingtalk(alert: AlertOut) -> None: ...
def send_email(kind: str, subject: str, body: str, to: str | None = None) -> None: ...
```

对接：`NOTIFY_MODE=http`，填 `DINGTALK_WEBHOOK` 等。

### 4.3 前端页面 ↔ 接口（E 消费，不实现后端）

| 页面 | 调用 |
|---|---|
| 登录 | `POST /api/auth/login` → `{"username":"demo","password":"demo123"}` |
| 首页 | `GET /api/news`、`GET /api/alerts` |
| AI 助手 | `POST /api/chat` |
| 知识库 | `POST /api/knowledge/upload`、`GET /api/knowledge/search` |
| 情报 | `GET /api/news`、`POST /api/analyze`、`GET /api/reports` |
| 预警 | `GET /api/alerts`、`POST /api/alert/evaluate`、`POST /api/notify/*` |

登录响应：

```json
{"access_token": "eyJ...", "token_type": "bearer"}
```
